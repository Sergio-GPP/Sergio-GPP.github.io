// El reto

La empresa trabajaba con una infraestructura de email marketing de gran volumen. Miles de buzones conectados, diferentes campañas activas, datos repartidos entre herramientas y procesos críticos que dependían de revisión manual.

Los principales retos eran controlar la salud y reputación de miles de buzones, detectar buzones saturados o con baja reputación, evitar envíos a contactos dados de baja o con rebotes repetidos, y reducir la dependencia de hojas de cálculo en procesos de alto volumen.

Además, el equipo necesitaba crear campañas de forma más rápida manteniendo criterios de segmentación, copy, horarios y límites por buzón, y tener una vista clara de lo que estaba pasando en producción.

// La solución

Seis módulos conectados para una operativa integrada

Se desarrolló una arquitectura integral de automatización conectada a las herramientas reales del cliente.

01

Dashboard operativo en tiempo real

Dashboard web conectado a MySQL para consultar el estado de campañas, buzones, acciones automáticas, errores y métricas operativas sin entrar en cada herramienta por separado.

Campañas activas Reputación Warmup Errores Históricos
02

Migración de datos a MySQL

Se consolidó MySQL como fuente operativa principal para monitores, dashboard y centro de bajas, eliminando las limitaciones de rendimiento de las capas legacy con miles de registros.

Estabilidad Sin límites escritura Escalable
03

Flujos n8n para monitorización

Flujos de automatización para inventario de buzones, monitorización de campañas, rotación de buzones, snapshots diarios, aperturas horarias y gestión global de errores.

8 flujos Inventario Rotación Snapshots
04

App de campañas con IA

Aplicación interna para crear campañas en Smartlead en borrador: descarga audiencias desde Zoho, filtra leads, genera copy con IA, crea secuencias A/B y selecciona buzones automáticamente.

Zoho CRM OpenAI A/B testing Borrador
05

Centro de bajas y compliance

Sistema para procesar rebotes hard y soft, unsubscribes, sincronización con lista global de bloqueo, registro histórico y trazabilidad de eventos.

Hard bounce Soft bounce Unsubscribe Bloqueo global
06

Clasificación de respuestas con IA

Clasificación automática entre respuestas humanas y automáticas para reducir falsos positivos de autoresponders y priorizar las respuestas que pueden convertirse en oportunidad comercial.

NLP Autoresponders Priorización

Automatizar email marketing no es solo enviar más correos. Es tener control sobre cada buzón, cada campaña y cada contacto, y que el equipo pueda operar con visibilidad y sin procesos manuales.

// Lo que hace diferente a este proyecto

De operativa fragmentada a sistema integrado

La empresa pasó de una operativa fragmentada a un sistema integrado, con datos centralizados y automatizaciones conectadas a sus herramientas principales.

No se trató de sustituir herramientas, sino de conectarlas. Smartlead, Zoho CRM, Zoho Analytics y MySQL trabajan ahora como un sistema coordinado, con n8n orquestando los flujos y una app interna como punto de entrada para crear campañas.

El control humano se mantiene en el lanzamiento final: las campañas se crean como borrador y el equipo decide cuándo activarlas. La automatización elimina lo repetitivo, no la decisión.
